# Project Summary

Modelmath is a browser-based toolkit for comparing AI inference options. It helps users estimate API costs, check whether local models fit their hardware, and explore preconfigured model-and-hardware comparisons alongside guides, FAQs, and reference content.

The product includes API-cost and VRAM calculators, a searchable calculator directory, educational and legal pages, and build-time prerendering for public routes. Its Python backend supports authentication, user accounts, settings, storage, AI Hub services, and now public contact-message submissions. Contact messages are stored privately in the project database; they are not emailed to the support address.

# Project Module Description

- **API cost calculator:** Estimates token usage and monthly costs across supported models. Includes provider filtering, charts, comparisons, shareable URL state, CSV export, and locally saved presets.
- **VRAM calculator:** Estimates model weights, KV cache, and overhead against hardware capacity. Reports fit status, maximum context, highest fitting quantization, and an estimated throughput tier.
- **SEO calculator pages:** Displays preconfigured VRAM comparisons with calculator state, verdicts, analysis, FAQs, and related links.
- **SEO generation and prerendering:** Generates model-and-hardware pages and renders public routes to HTML with route-specific metadata. A sitemap and fixed canonical origins require `VITE_SITE_ORIGIN`.
- **Content and directory:** Provides guides, reference tables, FAQs, blog routes, and a searchable calculator directory.
- **Site shell and trust pages:** Provides navigation, theme support, conditional ad slots, and about, contact, privacy, terms, authentication callback/error, and not-found pages. Theme selection is applied before page display to prevent a dark-mode flash.
- **Contact form:** Validates submissions, provides sending and error states, and quietly drops spam-bot submissions. Messages are stored in a private `contact_messages` table and are not emailed; users must check the backend data view.
- **Backend API:** Provides authentication, user and settings endpoints, object storage, AI Hub services, health checks, database access, and the public contact submission endpoint. Includes request telemetry and migration support.
- **Frontend authentication:** Shares authentication state through `AuthContext`, provides authentication utilities, and supports protected admin routes and a logout callback page.

# Technology Stack

- **Frontend:** React, TypeScript, Vite, Tailwind CSS, PostCSS, shadcn-style UI components.
- **Backend:** Python API application, SQLAlchemy, and Alembic migrations.
- **Application features:** Client-side calculators, URL-synced state, browser local storage, authentication context, and API clients.
- **Build and deployment:** Vite build-time prerendering and a serverless backend handler.

# Usage

Install frontend dependencies and start the development server:

```bash
cd app/frontend
npm install
npm run dev
```

Generate SEO calculator pages and build the frontend:

```bash
cd app/frontend
pnpm run generate:seo
npm run build
```

To generate fixed canonical addresses and a sitemap, configure `VITE_SITE_ORIGIN` with the production site origin before building. To enable ad slots, configure `VITE_ADSENSE_CLIENT`.

Run frontend validation:

```bash
cd app/frontend
npm run lint
npx tsc -b
```

Install backend dependencies in a Python virtual environment:

```bash
cd app/backend
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

See `app/backend/README.md` and `app/start_app_v2.sh` for backend and combined application startup instructions.
